## How to Customize This Site

Each page is a standalone HTML file and can be updated with your own information.

### Update personal identity
Edit the content in:

- `index.html`
- `about.html`
- `cv.html`
- `contact.html`

### Update research profile
Add or revise details in:

- `research.html`

Add associated images in:

- `assets/images/`

### Add documents and PDFs
Place academic files, CVs, certificates, or supporting material in:

- `files/`

### Update links and profiles
Replace placeholders such as:

- LinkedIn
- X/Twitter
- ORCID
- institutional or departmental pages
- email address

## Local Development

Because this is a static site, you can preview it locally without any framework or build step.

### Option 1: Open directly in browser
Simply open `index.html` in your browser.

### Option 2: Use a local web server
If you want a smoother preview, run a simple local server in the project folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deployment on GitHub Pages

This repository is already structured for GitHub Pages deployment.

### Recommended setup

1. Go to your GitHub repository.
2. Open Settings.
3. Click Pages.
4. Under Source, choose:
   - Branch: `main`
   - Folder: `/root`
5. Save.

Because this repository is named `muhammadab-bas.github.io`, GitHub Pages will publish it as:

```text
https://muhammadab-bas.github.io/
```

## Where to Place the README

The `README.md` file should be placed in the repository root, alongside files such as:

- `index.html`
- `about.html`
- `cv.html`
- `research.html`

This is the correct location for GitHub to display it on the repository homepage.

Important:

- `README.md` does not affect your website layout.
- GitHub Pages serves the website from the repository content, not from the README file.
- Keeping the README in the root is the standard and recommended practice for project documentation.

## Recommended README Purpose for Academic Websites

For a personal academic website, the README should help future viewers and collaborators quickly understand:
